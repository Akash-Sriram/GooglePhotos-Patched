# Google Photos Patched Releases

Automated builds and releases for **Google Photos Patched**, powered by custom Morphe patches from [Akash-Sriram/De-Vanced](https://github.com/Akash-Sriram/De-Vanced).

---

## ✨ Key Features

- 📸 **Built-in Photo Editor**: Full offline editing tools (**Enhance, Dynamic, Boost, Auto, Crop, Adjust, Actions, Markup**).
- ☁️ **Unlimited Original Quality Backup**: Full Google Pixel experience spoofing.
- 🎨 **Modern UI Presets**: Floating Date Pill (`[ Today ]`), Redesigned Collections Shelves V2, Floating Navigation Bar, Gemini AI / Ask Photos Tab, and Memories Stories.
- 🚩 **In-App Phenotype Flag Manager**: Live feature flag editor in **Settings > Morphe Flags** (search, add, edit, delete, import, export, reset).
- 👤 **Account Avatar Bridge & Persistence**: Google profile photo support and rock-solid account persistence across restarts.
- 🔄 **In-App Update Checker**: Automatic notifications when new patched builds are available.

---

## 📥 Downloads

Download the latest patched APK directly from the [Releases](https://github.com/Akash-Sriram/GooglePhotos-Patched/releases) tab.

> [!IMPORTANT]
> Non-root devices require **MicroG / GmsCore** installed for Google account authentication.

---

## ⚙️ Automated CI/CD Workflow
- Automatically tracks and scrapes new official Google Photos (`nodpi`, `arm64-v8a`) releases from APKMirror every 6 hours.
- Compiles the latest Morphe patches from [Akash-Sriram/De-Vanced](https://github.com/Akash-Sriram/De-Vanced).
- Patches, aligns, signs, and publishes the APK automatically.
