# Google Photos Patched

Automated builds of Google Photos patched via [Morphe Google Photos](https://github.com/Akash-Sriram/morphe-google-photos).

Rebuilt every 6 hours using base APKs from [APKMirror](https://www.apkmirror.com/apk/google-inc/photos/) ([Universal nodpi](https://www.apkmirror.com/apk/google-inc/photos/variant-%7B%22dpis_slug%22%3A%5B%22nodpi%22%5D%2C%22arches_slug%22%3A%5B%22arm64-v8a%22%2C%22armeabi-v7a%22%2C%22x86%22%2C%22x86_64%22%5D%7D/)).

📥 **Downloads**: [Latest Release](https://github.com/Akash-Sriram/GooglePhotos-Patched/releases/latest)  
🔑 **Prerequisite**: [MicroG-RE](https://github.com/MorpheApp/MicroG-RE/releases/latest) *(non-root Google sign-in)*

---

### 📦 Package Flavors (Non-Root)

| Package | Asset Name | Package ID | Usage |
|:---|:---|:---|:---|
| **Mod** *(Recommended)* | `GooglePhotos-v<ver>-mod.apk` | `app.morphe.android.apps.photos` | Installs alongside stock Google Photos. Works on all devices. |
| **Original** | `GooglePhotos-v<ver>-original.apk` | `com.google.android.apps.photos` | Stock package name (requires stock app uninstalled / custom ROM). Includes Play Store update blocker. |
